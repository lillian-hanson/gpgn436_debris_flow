Debris-Flow Runout Explorer

1D depth-averaged flow with Coulomb/Voellmy friction, solved in your browser (Python + NumPy via Pyodide). A tool for building intuition about what controls runout. Not a hazard-prediction tool.

Model limits

  • Width-averaged 1D: no lateral spreading or overbank flow.
  • Constant effective friction: no pore-pressure evolution and no entrainment.
  • Single-phase mixture.
  • The flux-limited Lax-Wendroff scheme drops to first order at the front, so the front is smeared, and runout shifts by a few metres with grid and stopping rule.
  • φ and ξ trade off against each other, so matching one runout distance identifies neither.
  • The φ and ξ ranges under the sliders are suggestions from RAMMS, a model with yield-stress and terrain-curvature terms this one lacks. They are a guide, not calibrated values for this model, and flow type is not a material property.
  • The run stops when the front stops advancing; a thin film may still be draining down the upper reach.

Verification against the Ritter and Stoker dam-break solutions and steady Voellmy flow: see verification/ritter_dam_break.ipynb in the repository.

Friction ranges: RAMMS::DEBRISFLOW User Manual v1.8.0 (RAMMS AG / WSL SLF, July 2024), eq. 3.1 and §5.1, Table 5.3, p. 83. RAMMS writes the friction law as S = μN + ρgu²/ξ, the same convention used here. The manual calls these values "only suggestions, not fixed definitions."
